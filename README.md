# 🪷 ประมวลภาพงานอุปสมบท พี & ฟิล์ม | Ordination Ceremony Gallery

เว็บไซต์ประมวลภาพและบรรยากาศอันน่าปิติยินดีในงานอุปสมบทของ **นาย พีรพล (พี) ชนประชา** และ **นาย รังสิพล (ฟิล์ม) ชนประชา** ออกแบบมาอย่างประณีตด้วยสุนทรียภาพที่เรียบง่าย สงบ และพรีเมียม (Serene & Gold Minimalist UI)

---

## ✨ คุณสมบัติเด่นของระบบ (Key Features)

*   **ไทม์ไลน์เหตุการณ์ประวัติศาสตร์ (Timeline View)**: แสดงรายละเอียดกำหนดการพิธีของทั้งสองวันพร้อมพรีวิวภาพเหตุการณ์ตามจริง
*   **คลังภาพพร้อมระบบค้นหาและตัวกรอง (All Gallery with Filters)**: กรองดูภาพตามพิธีการย่อย (ปลงผม, รับนาค, ทำขวัญ, โต๊ะจีน, อุปสมบท, ฉลองพระใหม่, ทั่วไป) พร้อมค้นหาชื่อไฟล์ภาพได้ทันที
*   **สไลด์โชว์ขยายภาพพร้อมการซูมและควบคุม (Premium Lightbox Slideshow)**: 
    *   รองรับการซูมเข้า-ออก (Interactive Zoom) และการลากเลื่อนรูปภาพ (Drag & Pan)
    *   มีปุ่มลูกศรนำทางและรองรับการ **ปัดหน้าจอซ้าย-ขวา (Swipe Gestures)** เพื่อสลับรูปภาพได้อย่างลื่นไหลบนมือถือ
    *   ปุ่มดาวน์โหลดภาพความละเอียดสูงจากต้นทาง Google Drive โดยตรง
*   **ระบบเสียงบรรเลงสมาธิ (Serene Audio)**: ปุ่มควบคุมเสียงดนตรีบรรเลงสไตล์เซนเพื่อความสงบผ่อนคลายขณะรับชมภาพ พร้อมตัวแจ้งเตือน Equalizer คลื่นเสียงดนตรี
*   **สลับโหมดสว่าง-มืด (Light/Dark Theme)**: ออกแบบโทนสี HSL อบอุ่นถนอมสายตา ปรับเปลี่ยนง่ายผ่านปุ่ม Navigation Bar
*   **หน้าดาวน์โหลดเริ่มต้น (Dynamic Loader)**: มีแอนิเมชันคำพูดสลับหมุนเวียนคอยอัปเดตขณะระบบประมวลผลดึงไฟล์ภาพจาก API เพื่อความต่อเนื่องในการเข้าชม
*   **บทกรวดน้ำแผ่ส่วนกุศล (Merit Dedication)**: การ์ดข้อความบทกรวดน้ำอุทิศส่วนบุญกุศลจากการบวชในหน้าราชพิธีแรกเพื่อการร่วมอนุโมทนาบุญ

## 🎵 การตั้งค่าระบบเสียงบรรเลงให้ทำงาน (How to Setup Music)

เพื่อการทำงานที่รวดเร็วและเสถียรที่สุดในหน้าเว็บ:
1.  ให้หาดาวน์โหลดไฟล์เสียงบรรเลงสมาธิ (เช่น นามสกุล `.mp3`)
2.  ตั้งชื่อไฟล์เสียงว่า `ambient.mp3`
3.  นำไฟล์มาวางไว้ที่โฟลเดอร์หลักของโปรเจกต์นี้ข้างๆ ไฟล์ `index.html` 
*   *หมายเหตุ: หากไม่มีไฟล์ `ambient.mp3` อยู่ในระบบ เว็บไซต์จะดึงเสียงดนตรีบรรเลงสำรองแบบออนไลน์จากลิงก์สำรอง (Fallback URL) ให้โดยอัตโนมัติ*

## 🚀 วิธีอัปโหลดและเปิดใช้งานบน GitHub (Deployment Guide)

### 1. นำไฟล์ขึ้น GitHub Repository
1.  สร้าง Repository ใหม่บนบัญชี GitHub ของคุณ (เช่น ตั้งชื่อว่า `ordination-gallery`)
2.  เปิดโปรแกรม Git ในเครื่องคอมพิวเตอร์ของคุณ แล้วรันคำสั่ง:
    ```bash
    git init
    git add .
    git commit -m "Initial commit for Ordination Gallery"
    git branch -M main
    git remote add origin https://github.com/ชื่อผู้ใช้ของคุณ/ordination-gallery.git
    git push -u origin main
    ```

### 2. ตั้งค่าให้เว็บใช้งานได้ผ่าน GitHub Pages (ใช้งานฟรี)
1.  ไปที่หน้าหน้าหลักของ Repository ของคุณบน GitHub
2.  คลิกที่แท็บ **Settings** ด้านบน
3.  ในเมนูด้านซ้าย เลือกหัวข้อ **Pages** (อยู่ในส่วนของ *Code and automation*)
4.  ภายใต้หัวข้อ **Build and deployment** > ให้เลือก **Source** เป็น `Deploy from a branch`
5.  ภายใต้หัวข้อ **Branch** > ให้เลือกเป็น `main` และโฟลเดอร์เป็น `/ (root)` จากนั้นกดปุ่ม **Save**
6.  รอประมาณ 1-2 นาที GitHub จะประมวลผล และแสดงลิงก์เว็บไซต์ของคุณด้านบน เช่น `https://ชื่อผู้ใช้ของคุณ.github.io/ordination-gallery/` ซึ่งสามารถเปิดเข้าใช้งานได้จริงทันทีผ่านมือถือและคอมพิวเตอร์

## ⚙️ การเชื่อมโยงคลังภาพสดจาก Google Drive (Backend Setup)

เว็บไซต์นี้ดึงข้อมูลชื่อภาพและ URL สดๆ จากโฟลเดอร์ Google Drive ผ่านบริการ **Google Apps Script** (Web App):
*   หากต้องการสลับฐานข้อมูลภาพ ให้แก้ไขลิงก์ Web App API ตรงฟังก์ชัน `loadImages()` ในไฟล์ `index.html` (ประมาณบรรทัดที่ 712)
*   คุณสามารถใช้ระบบในหน้า `sorter.html` เพื่ออำนวยความสะดวกในการจัดหมวดหมู่รูปภาพพร้อมๆ กันหลายภาพ และนำโค้ด JSON ที่ได้ออกมาอัปเดตลงในไฟล์ `config.js`
